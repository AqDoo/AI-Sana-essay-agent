## Быстрый старт

### 1. Установка

```bash
cd essay_agent
pip install -r requirements.txt
```

### 2. Получение API ключей

#### Gemini API — БЕСПЛАТНО (AI детекция + оценка качества)
1. Перейдите на https://aistudio.google.com/app/apikey
2. Войдите через Google аккаунт
3. Нажмите "Create API key" → скопируйте ключ (формат: `AIzaSy...`)

#### Serper API — БЕСПЛАТНО (плагиат, 2500 запросов)
1. Перейдите на https://serper.dev
2. Нажмите "Get Started" → зарегистрируйтесь через Google
3. Скопируйте API ключ из личного кабинета

### 3. Запуск

```bash
streamlit run app.py
```

Приложение откроется на http://localhost:8501

## Переменные окружения (.env)

Создайте файл `.env` в папке `essay_agent/`:

```
GEMINI_API_KEY=AIzaSy...
SERPER_API_KEY=xxxxxxxx...
```

Установите python-dotenv:
```bash
pip install python-dotenv
```

Добавьте в начало `app.py`:
```python
from dotenv import load_dotenv
load_dotenv()
```

## Антиплагиат

**Ожидаемый результат:** Serper найдёт совпадение и покажет ссылку на источник.

**Q: Gemini возвращает ошибку 404**
A: Модель обновилась — используем `gemini-2.5-flash-lite`

**Q: Serper не работает**
A: Проверьте ключ на serper.dev, убедитесь что вставили в поле "Serper API Key"

**Q: Хочу запустить без Serper**
A: Работает — плагиат проверяется локальным методом (приблизительно)

**Q: Казахский текст не определяется**
A: Gemini официально поддерживает казахский с 2025 года
